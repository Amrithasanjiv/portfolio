# Amritha Sanjiv — Editorial Portfolio

A modern, high-fashion editorial luxury portfolio for Amritha Sanjiv, B.Tech Computer Science & Engineering student specializing in Full-Stack Web Development, Artificial Intelligence, and Machine Learning.

## ✨ Features
- **Editorial Luxury Design**: Tailored Burgundy (`#220810`) and Cream Parchment (`#f6eee5`) color palette with Playfair Display and Cormorant Garamond typography.
- **Interactive AI Resume Classifier**: Interactive TF-IDF and Multinomial Naive Bayes simulation playground.
- **Viewable & Printable Resume Modal**: Formatted print/PDF ready resume modal.
- **Connected Contact Form & Live Message Inbox**: Direct email dispatch to `sanjivamritha@gmail.com` via FormSubmit with on-site message viewer.
- **Fluid Responsiveness**: Fully responsive across mobile, tablet, and widescreen desktop displays.

## 🚀 Technologies Used
- HTML5 & Modern Semantic Web Standards
- Vanilla CSS3 (Custom properties, CSS Grid, Flexbox, Glassmorphism)
- Vanilla JavaScript (ES6+)
- Font Awesome 6 Icons
- Google Fonts (Playfair Display, Cormorant Garamond, Plus Jakarta Sans, Italianno)

## 💻 Running Locally
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080` in your web browser.
